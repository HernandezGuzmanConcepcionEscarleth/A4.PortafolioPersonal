## Secciones de mi portafolio

Mi portafolio está dividido en diferentes secciones para organizar mejor la información.

### Inicio

Es la primera parte que se muestra al entrar al portafolio. En esta sección coloqué mi presentación principal y una fotografía para que el sitio tenga una presentación más personal.

### Sobre mí

En esta sección agregué información sobre mí y sobre mi formación. Su objetivo es que las personas que visiten mi portafolio puedan conocer un poco más acerca de mí.

### Habilidades

Aquí muestro algunas de las tecnologías, herramientas y conocimientos que he adquirido y otros que me interesa seguir desarrollando.

### Proyectos

En esta sección agregué algunos de los proyectos y trabajos que he realizado. Los proyectos están organizados para que sea más fácil visualizar los diferentes trabajos.

### Formación

Esta sección utiliza un carrusel para mostrar diferentes elementos. Para su funcionamiento se utiliza la librería Swiper.

### Contacto

Finalmente, agregué una sección de contacto para mostrar los medios por los cuales pueden comunicarse conmigo.

## Proceso de creación

Para realizar mi portafolio primero descargué la plantilla y revisé los archivos que contenía para entender cómo estaba organizada.

Después abrí el proyecto en Visual Studio Code y comencé modificando el archivo `index.html`. Cambié los textos que venían originalmente en la plantilla y los sustituí por mi propia información.

Posteriormente cambié las imágenes de la plantilla y agregué mi fotografía y las imágenes correspondientes a mis proyectos.

Después modifiqué el archivo `style.css`. En esta parte cambié principalmente los colores de la plantilla para utilizar una combinación de tonos cafés y colores claros, ya que quería que mi portafolio tuviera una apariencia sencilla y elegante.

También adapté algunas secciones, espacios, botones y elementos para que la información se mostrara de la manera que necesitaba.

En la parte de JavaScript revisé las funciones que utilizaba la plantilla. Conservé las necesarias para el funcionamiento del portafolio, como el filtro de proyectos y el carrusel de testimonios.

Una vez terminadas las modificaciones probé el portafolio en el navegador para comprobar que las imágenes, botones, secciones y demás elementos funcionaran correctamente.
